# Metastrip detection rules — which metadata counts as an "AI tag" when checking files.
# version: 2026.10.30
#
# "Check for Updates" downloads a newer copy of this file (see RULES_URL in update.sh), so new
# AI tools and new tagging standards can be added without rebuilding the app. Bump the version
# line above whenever you change it; the newest version (bundled or downloaded) wins.
#
# One rule per line, fields separated by a TAB or by 2+ spaces:
#   KIND   TAG-PATTERN   VALUE-PATTERN   LABEL
#
#   KIND  ai     an AI / Content Credentials tag (file is flagged red)
#         info   other identifying metadata (shown, but not flagged as AI)
#         bytes  raw text to look for in the first and last 8 MB of the file, for AI data that
#                ExifTool can't read yet (TAG-PATTERN is the exact text; VALUE-PATTERN is ignored)
#   TAG-PATTERN    regular expression on "Group:Tag" as ExifTool names it (e.g. XMP-iptcExt:DigitalSourceType)
#   VALUE-PATTERN  regular expression on the tag's value, or * for any value
#   Matching ignores upper/lower case. The first matching rule wins, so ai rules go before info rules.

# ---------------------------------------------------------------- Content Credentials (C2PA)
ai     ^(jumbf|c2pa|cbor)[^:]*:            *    Content Credentials (C2PA)
bytes  c2pa.claim                          *    Content Credentials (C2PA) data block
bytes  c2pa.actions                        *    Content Credentials (C2PA) data block
bytes  c2pa.hash.data                      *    Content Credentials (C2PA) data block

# ---------------------------------------------------------------- IPTC "made by AI" labels (used by Meta, Google, Adobe, OpenAI, Midjourney…)
ai     :digitalsourcetype$                 algorithmicmedia|compositesynthetic|trainedalgorithmic    Marked as AI-generated (IPTC)
ai     :(aipromptinformation|aipromptwritername|aisystemused|aisystemversionused)$    *    AI prompt / AI system (IPTC)

# ---------------------------------------------------------------- AI image generator settings stored in PNG text
ai     ^png[^:]*:(parameters|prompt|negativeprompt|workflow|invokeai_?metadata|sd-?metadata|dream|fooocus_scheme|generation_data)$    *    AI generator settings / prompt
